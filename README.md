# This repository has moved

**ArdunixNix6 / ArdunixNix4** is no longer maintained here.

### ➡️ New home: [github.com/isparkes/arduino-nixie-clocks](https://github.com/isparkes/arduino-nixie-clocks)

All firmware for the Arduino based Nixie clocks — 6-digit, 4-digit and the
ESP8266 WiFi time provider — now lives in that single repository, together
with the supporting libraries.

Please update your bookmarks, clones and forks:

```sh
git remote set-url origin https://github.com/isparkes/arduino-nixie-clocks.git
```

The source that used to be in this repository is still available in this
repository's git history, but it will not receive any further updates.
Issues and pull requests should be opened against the new repository.
